    How to update this record

    This file is a manual record. The automated dashboard refresh never touches it. To add an entry, tell Claude something like:

    "add clinical: BP 128/82 on 2026-09-05" or "add clinical: started ibuprofen 400mg for a strained shoulder"

    Claude reads your message and writes the corresponding row(s) into clinical-data.json. The shape (any field may be omitted) is:

    {
  "markers": [{"d":"YYYY-MM-DD","bp_sys":n,"bp_dia":n,"glucose":n,"hba1c":n,
               "tc":n,"ldl":n,"hdl":n,"tg":n,"creat":n,"egfr":n,
               "alt":n,"ast":n,"ggt":n,"urate":n,"tsh":n,
               "ferritin":n,"vitd":n,"waist":n,"note":""}],
  "meds":     [{"d":"YYYY-MM-DD","name":"","dose":"","kind":"medication|supplement|nsaid","note":""}],
  "symptoms": [{"d":"YYYY-MM-DD","type":"chest_pressure|dyspnoea|palpitations|near_syncope|ruq_pain|dark_urine|other","note":""}]
}
