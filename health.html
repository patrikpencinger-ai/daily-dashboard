    How to update this record

    This file is a manual record. The automated dashboard refresh never touches it. To add an entry, tell Claude something like:

    "add clinical: BP 118/76, pulse 61 on 2026-09-06" or "add clinical: started ibuprofen 400mg for a strained shoulder"

    Claude reads your message and writes the corresponding row(s) into clinical-data.json. The shapes (any field may be omitted) are:

    {
  "markers": [{"d":"YYYY-MM-DD","source":"lab|home",
               "bp_sys":n,"bp_dia":n,"pulse":n,
               "glucose":n,"hba1c":n,"insulin":n,"homa_ir":n,
               "tc":n,"ldl":n,"hdl":n,"tg":n,"creat":n,"egfr":n,
               "alt":n,"ast":n,"ggt":n,"urate":n,"tsh":n,
               "ferritin":n,"vitd":n,"plt":n,"hb":n,"wbc":n,"crp":n,
               "testosterone":n,"psa":n,"waist":n,"note":""}],
  "meds":     [{"d":"YYYY-MM-DD","stop":"YYYY-MM-DD|null","name":"","generic":"",
                "dose":"","kind":"medication|supplement|nsaid","purpose":"","note":""}],
  "symptoms": [{"d":"YYYY-MM-DD","type":"chest_pressure|dyspnoea|palpitations|near_syncope|ruq_pain|dark_urine|other","note":""}]
}
